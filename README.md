# Civilisation.One

**Understand Yourself – Understand the Universe – Improve Civilization**

This repository contains a 3-page web application:

1. **MirrorMe** – your personal AI engine.
2. **Thin Line Theory** – explore fundamental science.
3. **Civilisation Dashboard** – visualize and measure civilization progress.

The project is designed to run offline with local AI models and can be containerized via Docker for easier deployment.

## Current build direction

The repository now includes implementation instructions for two connected layers:

- **Civilisation One full-stack platform** — learning hub, research collaboration, AI tutor, virtual laboratory, sponsorship, Civilisation 2 profile, governance, audit logs, and privacy controls.
- **MirrorMe offline compact model** — local-first reasoning runtime with SQLite WAL, audit events, telemetry discipline, memory commands, and safe identity handling.

## Non-negotiable principles

- Evidence must be traceable.
- AI output must be labelled and open to correction.
- Scientific claims must be separated by evidence level.
- Participation in research must be voluntary and consent-based.
- Scores and recommendations must be explainable and contestable.
- MirrorMe must not invent access, memory, telemetry, or measurement.
